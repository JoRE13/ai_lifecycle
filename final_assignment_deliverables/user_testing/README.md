# User Testing Files

Use these files for your final-project user testing sessions.

## Google Docs workflow
1. Open `USER_TESTING_PACKET_GOOGLE_DOCS.md`.
2. Copy-paste into a new Google Doc (formatting will transfer well).
3. Duplicate `SESSION_NOTES_TEMPLATE.md` once per session (U1 to U5).
4. Use `SUS_FORM.md` during each debrief.
5. Store numeric SUS in `sus_responses_template.csv`.
6. Store findings in `findings_log_template.csv`.

## Files
- `USER_TESTING_PACKET_GOOGLE_DOCS.md`: facilitator script + tasks + protocol.
- `SESSION_NOTES_TEMPLATE.md`: per-session notes template.
- `SUS_FORM.md`: participant SUS form.
- `SUS_SCORING.md`: scoring instructions and formulas.
- `sus_responses_template.csv`: one row per participant.
- `findings_log_template.csv`: one row per finding.
